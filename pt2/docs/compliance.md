# Проверка оформления

Проверена папка проекта, которая размещается в `pt2`
публичного репозитория
[Aleksey-Dergachev-IKBO-71-25](https://github.com/AlexeyD26/Aleksey-Dergachev-IKBO-71-25).
Требования взяты со страниц 4–7 методички, сборник № 2.

## Повторная проверка

Из папки проекта:

```sh
npm run check
```

Команда последовательно запускает ESLint, проверку структуры и тесты.
ESLint 10.14.0 закреплён в команде `lint` и запускается через `npx`.
При первом запуске ему нужен интернет, затем используется кеш npm.
В зависимости самого приложения ESLint не добавлен.

Отдельные команды:

```sh
npm run lint
npm run check:repo
npm test
```

## Числа и комментарии

Код HTTP 404 и пороги длины имени пакета вынесены в именованные константы.
Для пустых массивов и Map используются проверки length и size.
Числа в тестовых данных, индексах массивов и описаниях версий остаются
данными; собственное правило ESLint проверяет именно операторы сравнений.

Код проекта оформлен без комментариев и JSDoc-блоков.
Назначение функций и их роль в программе описаны в README.
Формулировка К2 в методичке — «комментарии вместо документации JSDoc»;
отдельного требования снабдить JSDoc каждую функцию там нет.
Поэтому отсутствие JSDoc не выдаётся за проверку его полноты.

## Как устроены проверки

`eslint.config.js` задаёт ограничения длины строк, файлов и функций,
количества аргументов, сложности и стиля имён.
Функция `isNumericLiteral` распознаёт число в узле синтаксического дерева.
Правило `numericComparisons` находит числа в сравнениях,
правило `noComments` контролирует отсутствие комментариев.
Их обработчики `create`, `BinaryExpression` и `Program` вызываются ESLint.

В `scripts/check-repository.js` функция `git` читает список файлов и историю,
`checkStructure` проверяет обязательные файлы и каталоги,
`checkFile` — запрещённые файлы, размер и строки shell-скриптов,
`checkCommits` — формат сообщений коммитов.

Проверки дополнительно проверены на временных некорректных данных:
слишком длинных функциях и файлах, высокой сложности, лишних аргументах,
неверных именах, числах в сравнениях, комментариях, архиве и бинарном файле.
Эти временные данные в проект не сохранены.
