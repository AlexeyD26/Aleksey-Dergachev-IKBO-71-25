# Эмулятор оболочки — вариант 7

Выполнены этапы 1–3: ввод команд, настройки и загрузка VFS.
Нужен Python 3.9 или новее. Дополнительные пакеты и сборка не нужны.
Все команды ниже выполняются из папки `pt1`.

## Запуск

```bash
bash run.sh --config config.xml
```

Без настроек: `bash run.sh`. Справка: `bash run.sh --help`.

## Файлы и функции

В `src/main.py`:

- `main()` запускает программу.
- `execute_command()` разбирает команду и её аргументы.
- `run_script()` выполняет команды из текстового файла.
- `run_repl()` читает команды с клавиатуры.

В `src/config.py`:

- `read_args()` читает параметры запуска.
- `load_config()` добавляет настройки из XML.
- `show_config()` выводит итоговые настройки.

В `src/vfs.py`:

- `load_vfs()` читает JSON-файл.
- `read_folder()` обрабатывает вложенные папки и декодирует файлы.

## Настройки

- `--vfs` — путь к JSON-файлу VFS.
- `--script` — путь к стартовому скрипту с командами.
- `--config` — путь к XML-файлу с настройками.

В XML используются теги `<config>`, `<vfs>` и `<script>`.
Пример есть в `config.xml`. Параметры запуска имеют приоритет над XML.
Относительные пути считаются от текущей папки терминала.

## Команды и VFS

`ls` и `cd` пока только выводят своё имя и аргументы. Кавычки поддерживаются.
`exit` завершает программу. Ошибочные строки стартового скрипта пропускаются.
Если в скрипте нет `exit`, после него начинается ввод с клавиатуры.

VFS — словарь папок и файлов в памяти. В JSON папка задаётся объектом,
а содержимое файла — строкой base64. JSON читается без изменения и распаковки.
Примеры VFS: `examples/vfs/minimal.json`, `files.json` и `deep.json`.

Пример запуска с параметрами:

```bash
bash run.sh --vfs examples/vfs/deep.json --script examples/start.txt
```

Пример ввода: `cd "my documents"`. Для проверки ошибки введи `unknown`.
