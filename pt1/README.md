# Эмулятор UNIX-оболочки — вариант 7

Первый этап: консольный прототип с циклом ввода команд (REPL).
Написан на Python, используются только встроенные библиотеки.

## Запуск

Нужен Python 3.9 или новее. Установка пакетов и сборка не требуются.
Команды выполняются из папки `pt1`:

```bash
python3 src/main.py
```

Или через скрипт запуска:

```bash
bash run.sh
```

## Структура

- `src/main.py` — код эмулятора.
- `tests/test_shell.py` — тесты.
- `run.sh` — скрипт запуска.
- `.gitignore` — исключения для служебных файлов.

## Функции и настройки

`main()` задаёт имя VFS и запускает цикл ввода команд.
Приглашение выглядит как `my-vfs> `. Имя можно изменить в переменной
`vfs_name`. На первом этапе это только имя: сама VFS ещё не загружается.

`execute_command(line)` разбирает строку с помощью `shlex.split()`.
Первый элемент списка — команда, остальные — её аргументы.
Текст в одинарных или двойных кавычках считается одним аргументом.
Пустая строка пропускается. Функция возвращает `True` при корректной
команде `exit` и `False` во всех остальных случаях.

## Команды

- `ls [аргументы]` — заглушка, выводит имя команды и список аргументов.
- `cd [аргументы]` — такая же заглушка.
- `exit` — завершает программу. Аргументы не допускаются.

У `ls` и `cd` пока нет ограничений на аргументы: они только выводятся.
Работа с файлами и переход между папками относятся к последующим этапам.

Неизвестная команда, незакрытые кавычки и аргументы у `exit` вызывают
сообщение об ошибке. После ошибки программа продолжает принимать команды.
Ctrl+C и окончание ввода (Ctrl+D в macOS/Linux) завершают эмулятор.

## Пример работы

```text
my-vfs> ls
Команда: ls; аргументы: []
my-vfs> cd
Команда: cd; аргументы: []
my-vfs> cd "my documents"
Команда: cd; аргументы: ['my documents']
my-vfs> ls "file one.txt" 'file two.txt'
Команда: ls; аргументы: ['file one.txt', 'file two.txt']
my-vfs>
my-vfs> hello
Неизвестная команда: hello
my-vfs> cd "broken
Ошибка ввода: No closing quotation
my-vfs> exit extra
Ошибка: exit не принимает аргументы.
my-vfs> ls after-error
Команда: ls; аргументы: ['after-error']
my-vfs> exit
Эмулятор завершён.
```

## Тестирование

```bash
python3 -m unittest discover -s tests -v
```

Пять тестов проверяют команды и кавычки, обработку ошибок,
пустые строки, выход по `exit` и окончание входных данных.
