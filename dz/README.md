# Транслятор конфигураций

Домашняя работа по конфигурационному управлению, вариант 7.
Грамматика входного языка описана в `src/parser.peggy`.

## Сборка и запуск

```sh
npm ci
npm run build
./run.sh --input config.txt
```

Ключ `--input` задаёт путь к входному файлу. Результат выводится в формате TOML.
Каждое объявление `var` становится ключом TOML. Ссылка `${имя}` подставляет
значение константы, объявленной выше. Повторные объявления считаются ошибкой.
